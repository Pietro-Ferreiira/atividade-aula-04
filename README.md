# AlphaMarket

Projeto de e-commerce fictício desenvolvido em **HTML5 puro**, com foco na criação de tabelas para catálogos de produtos e navegação entre páginas.

> ⚠️ **Aviso:** Este projeto foi desenvolvido exclusivamente para fins acadêmicos. Não utiliza estilização CSS nem scripts em JavaScript.

---

## 📌 Sobre o Projeto

O **AlphaMarket** simula uma vitrine digital de eletrônicos e acessórios dividida por categorias de produtos, permitindo a navegação nativa e o direcionamento para o checkout.
